# 班主任小助手 · 使用说明（第一期 MVP）

> 本地单机 · AI 驱动 · 数据不出本机。配套文档：《设计思路.md》《UI草图.html》

## 两种用法，选一种

| | 打包版（推荐给同事/其他电脑） | 源码版（本机开发调试） |
|---|---|---|
| 启动 | 双击 **dist\\班主任小助手.exe** | 双击 **启动工作台.bat** |
| 需要 Python | 不需要 | 需要 |
| 界面 | 独立窗口，无浏览器地址栏、无黑框 | 浏览器打开 127.0.0.1:8790 |

打包版说明：
- 单个 exe 即可运行，**数据默认保存在 exe 所在目录**（`config.json` / `data` / `files`），换电脑整个文件夹一起拷就行；也可在设置里改成任意文件夹。
- 启动时自动挑空闲端口（从 8790 开始），不会和已运行的实例冲突；关掉窗口即完全退出。
- 需要系统带 **WebView2 运行时**（Win11 自带；Win10 一般随 Edge 已装，若打不开窗口装一下即可）。
- 启动万一出错，exe 同级会生成 `_启动错误.log`，把它发给开发者即可定位。
- 重新打包：`python build_exe.py`（约 30 秒，产物覆盖 `dist\\班主任小助手.exe`）；打包后想自动验收跑 `python verify_exe.py`（检查窗口标题、端口、出厂状态、首页）。

**发给别人用**：直接把 `发布包\\班主任小助手\\` 整个文件夹压缩发送，里面是 exe + 使用说明。对方解压后双击 exe 即可，不需要装 Python。

## 快速开始（源码版）

1. **双击「启动工作台.bat」** —— 会自动打开浏览器进入 http://127.0.0.1:8790
   - 若浏览器没自动弹出，手动在浏览器地址栏输入 `http://127.0.0.1:8790`
   - 脚本会自动查找本机 Python（已内置探测顺序，正常无需配置）
2. 首次启动会出现**三步设置向导**：班级信息（名称/专业/人数）→ 学期（开学日期，用于自动推算当前周次）→ AI 配置
3. 用完关闭该窗口即停止服务；日常使用保持窗口开启即可
4. 服务若意外崩溃，脚本会在 10 秒后**自动重启**；重复双击也不会冲突（检测到已在运行会直接帮你打开页面）

## AI 接入（DeepSeek）

1. 打开 **⚙ 设置 → AI 模型**，粘贴你的 DeepSeek API Key（https://platform.deepseek.com/api_keys 获取）
2. Key 仅保存在本机 `config.json`，不会上传任何云端（仅对话内容在你主动提问时发给 DeepSeek 接口）
3. 之后在首页底部输入框或右侧对话栏直接说事，例如：
   - 「张子豪今天感冒发烧，请假一天」→ 确认卡片 → 写入，考勤/首页自动联动
   - 「新建待办：周五下午3点提醒我找刘思远谈心」
   - 「帮我写一份国庆放假安全通知」→ 生成草稿 → 复制到班级群
   - 「全班现在多少人？男女比例？」
4. 不配 Key 也能用：全部功能都可走表单手工录入

```

├─ dist\班主任小助手.exe    打包版，双击弹独立窗口
├─ build_exe.py  desktop.py  打包脚本 / 桌面启动器源码
├─ verify_exe.py            打包后自动验收（窗口标题/端口/出厂状态）
├─ 发布包\班主任小助手\       可直接发送的成品：exe + 使用说明
├─ config.json             班级/学期/AI配置（Key 在此，勿外传）
├─ app\
│  ├─ server\              Python 后端（数据层/AI层/Excel层/API）
│  └─ web\                 前端页面
├─ data\                   业务数据（JSON，学号为主键）
├─ files\
│  ├─ excel\  word\        导入导出的表格与报告
│  ├─ photos\              图片（下期开放上传）
│  └─ backups\             每次写入前的自动快照（按日期存放）
├─ 设计思路.md  UI草图.html
```

## 常见问题

- **双击后窗口一闪而过 / 打不开**：多半是本机 Python 环境变化。用记事本打开 `启动工作台.bat` 看最后 `echo [ERROR]` 提示，按其要求装一次依赖即可（见下）
- **手动装依赖**（仅需一次）：命令行执行 `python -m pip install fastapi uvicorn openpyxl python-docx httpx python-multipart`
- **端口被占用**：编辑 `启动工作台.bat`，把里面两处 `8790` 改成 `8791`（URL 与 --port）；exe 版会自动顺延端口，无需处理
- **exe 双击没反应 / 一闪而过**：看 exe 同级有没有 `_启动错误.log`；最常见是缺 WebView2 运行时，装一次微软官方 WebView2 Runtime 即可
- **exe 版数据在哪**：就在 exe 旁边（`config.json` / `data` / `files`）；想换位置去 ⚙ 设置 → 存储位置
- **换电脑/备份**：整个文件夹复制即可，数据零依赖
- **误删学生/写错数据**：⚙ 设置 →「撤销上一次写入」，或去 `files\backups\` 找当日快照恢复
