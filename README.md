项目特点：

1.**为高职设计** —— 针对高职院校特点，设置学业与成绩、实习与就业、思政与心理、家校沟通等板块，覆盖工作所需内容。

2. **琐碎信息高效整理** —— 可记录并自动整理学生出勤、谈话、考分等琐碎信息，形成可视化报表，方便工作留痕。

3. **数据不出本机** —— 所有学生信息只存在专用文件夹内，不上传任何云端；AI 只在调用大模型 API 时把"当次对话内容"发出去，落库全在本地。

4. **对话即录入** —— 一个对话框是核心入口，大部分信息靠打字告诉 AI，AI 理解后写入对应模块；表格页保留手工增改作为补充。

5. **一次录入、处处联动** —— 请假 → 自动进考勤 → 首页"本周到校"变化；成绩录入 → 自动触发学业预警 → 推送首页红黄灯；谈心/家访 → 自动进一生一档时间线。

6. **界面从简** —— 固定四块结构：顶部日程条 + 左侧导航 + 中间内容区 + 右侧 AI 对话栏，不随模块变化。

7. **可持续迭代** —— 数据全部 JSON 化、模块之间通过联动规则解耦，功能随时可加不改旧数据。所有数据可导出、迁移。
   
**使用建议：根据《教育部中小学生成式人工智能使用指南（2025年版）》，教师将个人信息、考试试题等敏感数据输入AI工具可能带来信息泄露风险，请教师朋友谨慎使用本软件的AI功能。建议将学生、家长的敏感信息（如身份证号、手机号、地址）做脱敏处理**。
